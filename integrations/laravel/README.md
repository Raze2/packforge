# packforge/laravel

Laravel client for the PackForge API (`pf-api`), plus the `<x-packforge-designer>` Blade
component. Supports Laravel 12 and 13 (PHP 8.2+).

## Install

```bash
composer require packforge/laravel
php artisan vendor:publish --tag=packforge-config   # optional: config/packforge.php
php artisan vendor:publish --tag=packforge-assets   # public/vendor/packforge/packforge-designer.js
```

`.env`:

```dotenv
PACKFORGE_URL=http://packforge:8080/v1
PACKFORGE_KEY=pk_live_...        # server-side only, never sent to browsers
```

## Server-side rendering and export

```php
use PackForge\Laravel\Facades\PackForge;

$design = PackForge::component('fefco-0201')
    ->params(['L' => 300, 'W' => 200, 'H' => 150])   // millimetres
    ->board('C-flute');                               // or ->caliper(3.2)

$result = $design->render();
$result->stats->blankWidth;    // 1051.0 (mm)
$result->stats->blankAreaM2;   // 0.3805
$result->warnings();           // ['…']

$dxf = $design->dxf();                       // or ->svg(), ->export('dxf')
$dxf->store("orders/{$order->id}/{$dxf->filename}");   // any filesystem disk
return $dxf;                                 // from a controller: downloads the file

// From a project saved by the designer (pf:save / pf:change event):
PackForge::design($order->project)->dxf();

PackForge::components();   // catalogue
PackForge::describe('fefco-0201');   // parameter schema
PackForge::boards();       // board presets
```

`Design` methods return new instances, so a base design can be reused safely.

### Errors

| Exception | When |
|---|---|
| `ValidationException` | Invalid parameters — `$e->messages()` gives `['L' => 'must be at least 40']` |
| `AuthenticationException` | Missing/invalid API key (401) |
| `NotFoundException` | Unknown component (404) |
| `RateLimitedException` | Too many requests (429) — `$e->retryAfter` seconds |
| `ConnectionException` | API unreachable / timeout |
| `PackForgeException` | Base class; `$e->status`, `$e->problemCode`, `$e->errors` |

Connection errors, 5xx and 429 responses are retried (`PACKFORGE_RETRIES`, default 2).

### Queued generation

```php
class GeneratePackagingFiles implements ShouldQueue
{
    use Queueable;

    public function __construct(public Order $order) {}

    public function handle(): void
    {
        try {
            $dxf = PackForge::design($this->order->project)->dxf();
        } catch (RateLimitedException $e) {
            $this->release($e->retryAfter);
            return;
        }
        $this->order->update(['dxf_path' => $dxf->store("orders/{$this->order->id}/box.dxf")]);
    }
}
```

## Blade component

```blade
<x-packforge-designer
    :project="$design->project"      {{-- or component="fefco-0201" :params="[...]" board="C-flute" --}}
    mode="configurator"               {{-- or "full" --}}
    theme="light"
    height="640px"
    id="designer"
/>
```

The live preview runs in the browser (WebAssembly), with no API calls while editing. Exports from
the designer's toolbar are posted to the package route `POST /packforge/export`
(`packforge.export`), which forwards them to the API with your key and the user's CSRF token.

Listen to the designer from your page:

```js
document.getElementById('designer').addEventListener('pf:change', (e) => {
  document.querySelector('input[name=project]').value = JSON.stringify(e.detail.project);
});
```

Always re-validate a submitted project on the server (`PackForge::design($project)->render()`).

### Export route

Configured under `packforge.export_route`: `enabled`, `uri`, `name`, `middleware`
(default `['web', 'throttle:60,1']` — add `auth` to restrict it) and allowed `formats`.
Pass `:export-endpoint="false"` to a component to keep exports browser-only (SVG/DXF from WASM).

## Testing

```bash
composer install
vendor/bin/phpunit
```

In your app, fake the API with `Http::fake(['*/render' => …, '*/export' => …])`.

## Releasing

`resources/dist/packforge-designer.js` is generated by `pnpm --dir apps/web build` (it is copied
here automatically) and must be included in the published package.
